# MCP/A2A adapter contract

The adapter translates MCP tool/resource calls and A2A task messages into the internal envelope without widening authority. Capability negotiation is explicit; unsupported methods fail with `PROTOCOL_ERROR`. Tool arguments and task artifacts are schema-validated, bounded by the global frame and batch limits, and attached to request/deadline IDs. Remote peers are authenticated and assigned an allowlisted capability set. Streaming chunks carry sequence numbers and a final marker; missing or duplicate chunks fail the stream rather than being silently reordered. Cancellation propagates best-effort and the adapter reports whether work may have completed. Remote errors are mapped to stable internal codes and retain the peer error only in bounded, redacted details. The adapter never handles secret values directly; it requests broker leases through the owning policy boundary.
