# MCP/A2A adapter contract

The adapter translates MCP tool/resource calls and A2A task messages into the internal envelope without widening authority. Capability negotiation is explicit; unsupported methods fail with `PROTOCOL_ERROR`. Every call has an absolute deadline propagated to downstream work; expired work is rejected before side effects and in-flight work is cancelled best-effort. Tool arguments and task artifacts are schema-validated and bounded by global frame/batch limits.

Remote peers are authenticated and assigned an allowlisted capability set. Streaming chunks carry sequence numbers and a final marker; missing or duplicate chunks fail the stream rather than being silently reordered. On transport loss the adapter reconnects only with bounded exponential backoff and jitter, within the original deadline; it must not duplicate non-idempotent work (request IDs provide deduplication). A circuit breaker opens after a configured consecutive failure threshold, rejects calls fast with `UNAVAILABLE`, and transitions through a probe/half-open state before close; deadlines and cancellation apply in every state. Remote errors map to stable internal codes with bounded, redacted details. The adapter never handles secret values directly; it requests broker leases through the owning policy boundary.
