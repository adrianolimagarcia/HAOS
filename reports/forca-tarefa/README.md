# Relatórios da força-tarefa

Esta pasta contém investigações reproduzíveis das falhas da suíte global. Cada relatório deve distinguir:

- OBSERVADO: saída diretamente executada;
- INFERÊNCIA: conclusão lógica baseada na evidência;
- DESCONHECIDO: ainda sem reprodução suficiente.

Nenhuma correção deve ser aplicada nesta fase de coleta sem autorização/escopo explícito.
