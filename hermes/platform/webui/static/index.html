i Arquitetura honesta

Task ≠ Run: cada missão do Console vira um TaskSpec no Kanban canônico SQLite; o scheduler determinístico (CPM + PIP + starvation age) ordena, o ConcurrencyGuard admite sob tetos globais/por-provider/por-modelo e a lane canônica executa. Todo ciclo de vida é projetado de forma fail-safe no EventStore append-only; falhas são classificadas e alimentam o loop Ouroboros em shadow mode. Esta UI nunca fabrica números: ausência de dado mostra estado vazio honesto.
